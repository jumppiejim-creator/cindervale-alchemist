## Prevalence Statement

**4 of 16 surveyed `mechDesc` strings have a code-truth issue = 25%.**

Slightly worse than the prior incidental ~20% rate from the sufficiency sweep, confirming that the field was systematically unaudited and that surfacing it required the per-string code verification this pass does.

## Re-verification of Prior Three Corrections

Three `mechDesc` strings had been corrected in an earlier sweep before this Phase 1 audit:

- **Sentinel** — re-verified TRUE against code. Lv3 nightExpeditions/nightBonusHours ✓, Lv6 guaranteedRare/nightDangerReduction ✓, Lv10 nightDCReduction:1/passiveThreatDecay:3/preemptiveStrike (50 Energy → reduce threat by 20) ✓. Prior correction accurate.
- **Theorist** — re-verified TRUE. Lv10 `doubleDiscovery` confirmed at `index.html:3007` (research finds 2 recipes when set), `citationCraftBonus`/`grandPapers` effects + scaling craft bonus all match. Prior correction accurate.
- **Spellweaver** — **re-verified WRONG**. The prior correction was itself an over-correction: it removed the real dual-plane Planar Convergence claim, missing the `canDual = swLv >= 10` code at `index.html:3509` and the 6 PLANAR_COMBOS at `game-data.js:2220-2226`. This Phase 1 surfaced the over-correction and led to a third correction (restoring the dual-plane claim, accurately worded). **This is the third correctness issue Spellweaver's `mechDesc` has had**: original wrongly promised dual-type capstone; first correction over-removed the dual-plane claim; second correction restored convergence but still claimed mechanical effects from planes and combos that the code never actually applies. The latter was discovered in a subsequent Phase 1 recon (Spellweaver in-game guidance task) and is the basis for a separate design-lock document.

## Logged Design Questions (from this audit)

Two Spellweaver-class cases — promised mechanics not implemented in code:

1. **Transmuter Lv6 "Convert potions between types"** — promised in both `mechDesc` and Lv6 feature `desc`, no implementation. The transmute screen at `index.html:10422-10478` only handles ingredient → ingredient. Building this is net-new game logic (potion source/target picker UI, potion-conversion handler, quality/freshness/infusion preservation rules). **Status: subsequently CLOSED by the Transmuter rework build — the capstone moved to Lv10 with full Potion Transmutation and P1+F1+I1 preservation policy.**

2. **Naturalist set-completion rewards** — promised in `mechDesc` ("Completed journal sets unlock discovery bonuses and region-specific recipes"), no implementation. Set completion only granted the cosmetic ★ Region Mastery badge. Building this is net-new game logic (per-region completion check hook, reward unlock table, recipe-grant pipeline). **Status: subsequently CLOSED by the Naturalist Region Mastery build — set completion now grants +5 max Energy/day per fully-mastered region.**
